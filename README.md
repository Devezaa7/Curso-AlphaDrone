# 🚁 Alpha Drone — Landing Page

Site de vendas de cursos de pilotagem de drones desenvolvido para um cliente da área. Projeto freelance entregue com deploy em produção.

🌐 **[alphadronebrasil.com.br](https://alphadronebrasil.com.br)**

---

## 🛠️ Tecnologias

![React](https://img.shields.io/badge/React-19-61DAFB?style=flat&logo=react)
![Vite](https://img.shields.io/badge/Vite-8-646CFF?style=flat&logo=vite)
![TailwindCSS](https://img.shields.io/badge/Tailwind-4-38BDF8?style=flat&logo=tailwindcss)
![Vercel](https://img.shields.io/badge/Deploy-Vercel-000?style=flat&logo=vercel)

- **React 19** + **Vite 8** — UI componentizada e build rápido
- **Tailwind CSS 4** — Estilização utilitária
- **react-icons** — Ícones sociais
- **Vercel** — Deploy contínuo a partir do GitHub
- **Kiwify** — Plataforma de pagamento integrada via links externos

---

## ✨ Funcionalidades

- Design dark com identidade visual personalizada
- Totalmente responsivo — mobile, tablet e desktop
- Menu hamburger no mobile
- Seção de vídeo com embed YouTube
- Cards de cursos com integração ao checkout
- Seção de instrutores com fotos e certificações
- Links diretos para WhatsApp e Instagram
- Domínio customizado configurado no Vercel
